## WarmStart

我们可以先做WarmStart，这在实现上更简单。

当物体堆叠，以及大质量物体压着小质量时，随着堆叠层数越高/物体间质量比越大，所需的PGS迭代次数会越来越多。

而WarmStart就是用上一帧的累计冲量作为PGS的起始点（等于是直接跳过了之前很多次迭代），这样可以显著减少PGS的迭代次数，在相同迭代次数下，系统会更加稳定。

### 局部点匹配

一种简单的思路是每次将`Manifold`转换成`SolverContact`时，将接触点在刚体局部坐标下的位置记录下来。等到下一帧时，当两个Shape检测到碰撞时，使用新生成的`Manifold`中的接触点和老的接触点比对，如果相似（位置差不多，且法向差不多），则直接继承老接触点的累计冲量。

首先在`SolverContact`中记录碰撞到的`Shape`和局部接触点：

```cpp
struct SolverContact {
...

const Shape* m_shape1{};
const Shape* m_shape2{};

Vector3 m_local1;
Vector3 m_local2;

...
};
```

然后写一个`CachedPoint`用来记录缓存下来的一对接触点信息：

```cpp
struct CachedPoint {
	Vector3 m_local1;
	Vector3 m_local2;
	Vector3 m_normal;
	
	// 累计冲量
	real m_normal_impulse;
	std::array<real, 2> m_tangent_impulses;
};
```

然后是`CachedManifold`，用来缓存一次`Manifold`中的所有接触点信息：

```cpp
struct CachedManifold {
	const Shape* m_shape1{}; // 存储原Manifold中的第一个shape，用来判断接触点是哪个Shape的（m_local1是shape1的。而m_local2就是另一个的）
	std::vector<CachedPoint> m_points;
};
```

然后在`RigidSolver`中记录下所有`CachedManifold`：

```cpp
using ShapePair = UnorderedPair<const Shape*, const Shape*>;
std::unordered_map<ShapePair, CachedManifold> m_cache;
```

这里`unordered_map`的`Key`是一对无序的`Shape*`，因为碰撞总是只发生在一对`Shape`中，我们要用这对`Shape`快速找到之前Cache的`Manifold`。

现在，整个`RigidSolver`流程变成这样：

```cpp
void RigidSolver::Solve(std::span<RigidActor*> actors, real dt) {
    // Step1: integrate velocities
    integrateVelocities(actors, dt, m_settings.m_use_gyro);

    // Step2: detect contact and generate manifolds
    m_contacts.clear();
    detectContacts(actors, dt);

    // Step3: [NEW] restore impulses from last frame and apply them
    if (m_settings.m_use_warm_start) {
        warmStartContacts();
    }

    // Step4: solve constraints
    solveVelocityConstraints();

    // Step5: [NEW] store impulses for next frame
    if (m_settings.m_use_warm_start) {
        storeImpulses();
    } else {
        m_cache.clear();
        m_frame = 0;
    }

    // Step6: integrate transform
    integrateTransforms(actors, dt);
}

```

在`detectContacts()`之后，使用`warmStartContacts()`进行暖启动。然后在解算完`solveVelocityConstraints()`得到最新的累计冲量之后，使用`storeImpulses()`将接触点和缓存冲量（即`CachedManifold`）存下来。

`warmStartContacts()`的实现很简单，只是找到对应`CachedManifold`并将累计冲量应用在物体上：

```cpp
void RigidSolver::warmStartContacts() {
	// 标记已匹配的接触点。一个旧接触点只能被一个新接触点匹配
    void RigidSolver::warmStartContacts() {
    std::unordered_map<ShapePair, std::array<bool, 4>> used_points;

    for (SolverContact& contact : m_contacts) {
        const ShapePair key{contact.m_shape1, contact.m_shape2};

        const auto it = m_cache.find(key);
        if (it == m_cache.end()) {
            continue;
        }

        const CachedManifold& cached = it->second;
        const bool flipped = cached.m_shape1 != contact.m_shape1;

        auto [used_it, inserted] = used_points.try_emplace(key);
        auto& used = used_it->second;
        if (inserted) {
            used.fill(false);
        }

		// 找到匹配的接触点。
		// 匹配规则是：两对接触点之间距离小于阈值，以及对应法线的夹角小于阈值
		// JoltPhysics是只检查两对点是否挨得近，没看法线
        const int match = findMatch(cached, contact, flipped, used);
        if (match < 0) {
            continue;
        }

		// 将旧接触点累计冲量迁移到新接触点
        const CachedPoint& point = cached.m_points[static_cast<size_t>(match)];

        contact.m_normal_impulse = point.m_normal_impulse;
        contact.m_tangent_impulses = point.m_tangent_impulses;

        const real max_friction = contact.m_friction * contact.m_normal_impulse;

		// 切向累计冲量可能有误，需要重新Clamp。比如你在两次模拟间改了Shape的摩擦系数
        for (real& tangent_impulse : contact.m_tangent_impulses) {
            tangent_impulse =
                std::clamp(tangent_impulse, -max_friction, max_friction);
        }

		// 将累计冲量应用在物体上
		// 因为当前帧的累计冲量是0，所以新累计冲量-旧累计冲量就是新累计冲量，
		// 所以直接应用
        applyContactImpulse(contact,
                            contact.m_normal * contact.m_normal_impulse);
        applyContactImpulse(contact,
                            contact.m_tangent1 * contact.m_tangent_impulses[0]);
        applyContactImpulse(contact,
                            contact.m_tangent2 * contact.m_tangent_impulses[1]);
    }
}
```

而存储`CachedManifold`时有不同的策略：

1. 如果新点有匹配的旧点，就用新点数据替换旧点，否则，将新点加入`CachedManifold::m_points`中。这样会导致点越来越多
2. 最多就存四个点。如果多于四个点，删掉最长时间不用的那个。这可能会导致某些新点对应的旧点信息失效
3. 只存这一帧的所有点，然后将上一帧匹配到的点的信息搬到新点上（JoltPhysics做法）。
4. 给每个点加上时间戳，每帧末尾看点是否超时，超时就去掉

我这里用的是策略3，直接照抄一手JoltPhysics。具体代码就不贴了，反正也很简单。


这是应用了WarmStart的结果（去掉了Baumgarte稳定化），可以看到堆叠确实更稳定了。

### 持久化接触流型(PCM)

PCM - Persistent Contact Manifold。

简单来说是利用了物理运动的连续性。上一帧碰撞的物体这一帧还是有可能碰撞。所以如果某一对`Shape`上一帧生成了`Manifold`，并且这一帧相对移动不大（相对位置，旋转几乎没变），那么就直接尝试生成`Manifold`，并使用WarmStart中介绍的碰撞点迁移方法将旧碰撞点的信息迁移到新碰撞点上。

生成新`Manifold`的时候也不走NarrowPhase，不走GJK，面剔除。旧的`Manifold`里面存储的都是接触点在物体局部坐标系下的值，新`Manifold`生成时直接使用旧接触点，只是会跟着物体的微小移动/旋转进行变换。

注意：新生成的`Manifold`只是这一帧临时使用，并不会存下来。所以旧的`Manifold`接触点一直没变，这样当物体相对位置偏差越来越大时，才会超出阈值从而不使用PCM。他不是每次生成新`Manifold`就存下来，这样会导致每帧都偏移一点点，经过很多帧后明明已经偏移很多了但是`Manifold`还是会生成的情况。

PCM只能应用在相对移动低速的情况下，不然会产生很多不该生成的接触点。

好处：

1. 加快性能：当能够产生新流形时，我们就知道物体一定相撞，这样无需经过BroadPhase & NarrowPhase，直接丢到解算器里求解
2. 数值稳定性：新流形继承了老流形的累计冲量，可以用于WarmStart

## 稳定化方法

### Block Solver

由Erin Catto在GDC2014上提出。这个方法主要用在2D物理引擎，3D下成本略贵，收益不高。我们也就不实现了。

![BlockSolver图解](/assets/从0开始编写物理引擎/BlockSolver图解.png)

Block Solver是指，物体碰撞的时候会有多个接触点，而现在的PGS是逐个接触点求解。但由于接触点都满足约束

$$
\begin{aligned}
& 0 \le x \perp Ax + b \ge 0 \\
& A = \pmb J_n S_{11} \pmb J_n^T \\
& x = \pmb p_n \\
& b = \pmb J_n \pmb r + \frac{C_n}{\Delta t} + \frac{\partial C_n}{\partial t}
\end{aligned}
$$
这个互补条件，我们可以使用“LCP小记”中的枚举方法，枚举互补条件中$\pmb x_i = 0$和$A\pmb x + b = 0$，从而一次性解出满足条件的$\pmb x$。

这样，对于2D来说，PGS本来要迭代两次，这里就变成迭代一次。减少了一半迭代次数。

对于3D来说，最多4个接触点，最好情况下可以减少4倍迭代次数。但要注意四个互补条件带来的枚举量也会上升，总体来说还不如直接用PGS。

### 位置层稳定化

注：使用位置层稳定化就不要使用速度层的Baumgarte Stability了。这两者相互冲突。

#### Pseudo Impulses/NGS

也是由Erin Catto在GDC2014上提出。在Bullet中叫Split impulse。本质上也是通过速度修正物体位置，但是这个速度是*伪速度*，修正完位置后直接丢弃，不会加到累计冲量上。所以本质上是位置层稳定化。

那么首先要理解位置约束的物理模型。注意位置约束是在整个约束求解完之后另做的一步，此时物体位置已经改变，但仍可能不满足$C \ge 0$的约束。我们需要加一个修正量$\Delta \pmb q$来让他满足：

$$
C_n(\pmb q + \Delta \pmb q) \ge 0
$$

那么这里的问题就是要如何确定$\Delta q$。将$\Delta \pmb q$写成速度形式：

$$
\Delta \pmb q = \Delta \pmb v \Delta t
$$
我们当然希望$\Delta q$是改变动能最小的量（即引入的能量最好最小），这样就是：

$$
\frac{1}{2}\Delta \pmb q^T M \Delta \pmb q = (\frac{1}{2}\Delta \pmb v^T M \Delta \pmb v) \Delta t^2
$$
这里$\Delta t$是每帧的迭代步长，是常量。所以原问题就等价于如下QP优化问题：
$$
\begin{aligned}
&\text{minimize} & \frac{1}{2}\Delta \pmb q^T M \Delta \pmb q \\
&\text{subject to} & -C_n(\pmb q + \Delta \pmb q) \le 0
\end{aligned}
$$
其KKT条件对应的拉格朗日函数为：

$$
L= \frac{1}{2}\Delta \pmb q^T M \Delta \pmb q - \lambda C_n(\pmb q + \Delta q)
$$
这里对$C_n$在$\pmb q$处展开，保留一阶项：

$$
C_n(\pmb q) + \frac{\partial C_n}{\partial \pmb q}\Delta \pmb q = C_n(\pmb q) + \pmb J_n \Delta \pmb q
$$
这样最终KKT条件就是：

$$
\begin{aligned}
& \frac{\partial L}{\partial \Delta \pmb q}: M\Delta \pmb q - \lambda\pmb J_n^T = 0 \\
&\Rightarrow \\
& \Delta \pmb q = \lambda M^{-1} \pmb J_n^T
\end{aligned}
$$

代回$C_n = 0$的泰勒展开，有：

$$
\begin{aligned}
&C_n(\pmb q) + \lambda \pmb J_nM^{-1}\pmb J_n^T = 0 \\
&\lambda = -\frac{C_n(\pmb q)}{\pmb J_n M^{-1} \pmb J_n^T}
\end{aligned}
$$
注意别忘了KKT条件中$\lambda \ge 0$的约束，这导致PGS中需要将$\lambda$进行clamp。

这里将其写成PGS的迭代格式就是：

$$
\lambda_{new} = \lambda_{old} + \frac{C_n(\pmb q)}{\pmb J_n M^{-1} \pmb J_n^T} = \frac{C_{new}(\pmb q) - C_{old}(\pmb q)}{\pmb J_n M^{-1} \pmb J_n^T}
$$

现在有两个做法：

1. 算出$\Delta \pmb q$，然后直接加到位置上。这个被Erin Catto叫做NGS（Nonlinear Gauss-Seidel），被他用于Box2D的3.0+版本
2. 将$\Delta q$除以$\Delta t$变为冲量，然后还是用冲量更新位置，这就是Split Impulse/Pseudo Impulse。

如果是要做Pseudo Impulse，则需要对$\Delta \pmb q$除以$\Delta t$，其实就是对$\lambda$除以$\Delta t$：


$$
\lambda_{new} = \frac{C_{new}(\pmb q) - C_{old}(\pmb q)}{\Delta t\pmb J_n M^{-1} \pmb J_n^T}
$$
我们代码里做的是Pseudo Impulse，代码核心部分如下：

```cpp
void RigidSolver::solvePositionConstraints(std::span<RigidActor*> actors,
                                           real dt) {
    const real slop = m_settings.m_penetration_slop;
    const real beta = m_settings.m_position_baumgarte;
    const real max_correction = m_settings.m_max_position_correction;

    // 1. 删除所有旧的pseudo impulse
    for (RigidActor* actor : actors) {
        DynamicRigidBody* body = actor->AsDynamic();
        if (body == nullptr) {
            continue;
        }
        body->m_pseudo_linear.setZero();
        body->m_pseudo_angular.setZero();
    }

    // 2. 根据更新后位置重算力臂和穿透深度
    for (SolverContact& contact : m_contacts) {
        contact.m_position_lambda = 0;

        const Transform& t1 = contact.m_body1->GetTransform();
        const Transform& t2 = contact.m_body2->GetTransform();

        const Vector3 p1 = t1.m_position + t1.m_rotation * contact.m_local1;
        const Vector3 p2 = t2.m_position + t2.m_rotation * contact.m_local2;

        contact.m_r1 = contact.m_dyn1 ? p1 - contact.m_dyn1->GetCenterOfMassPosition()
                          : p1 - t1.m_position;
        contact.m_r2 = contact.m_dyn2 ? p2 - contact.m_dyn2->GetCenterOfMassPosition()
                          : p2 - t2.m_position;

        contact.m_separation = (p2 - p1).dot(contact.m_normal);
    }

    // 3. 开始PGS迭代
    for (uint32_t iter = 0; iter < m_settings.m_position_iter_num; ++iter) {
        for (SolverContact& c : m_contacts) {
            if (c.m_normal_mass <= 0) {
                continue;
            }

            // C_n(q)
            const real depth = -c.m_separation - slop;
            if (depth <= 0) {
                continue;
            }

            // 算d lambda = (new_vn - old_vn)/JM^{-1}J^T
            const real vn_target =
                std::min(beta * depth / dt, max_correction / dt);

            const real vn = pseudoRelativeVelocity(c).dot(c.m_normal);
            const real delta = (vn_target - vn) * c.m_normal_mass;

            const real next = std::max<real>(0, c.m_position_lambda + delta);
            const real applied = next - c.m_position_lambda;
            c.m_position_lambda = next;

            if (applied != 0) {
	            // 累加lambda到累计位置上。这里是\Delta q，但是拆开算了：
	            // 算的是 lambda * J_n * M^{-1}。至于dt等到第四步位置更新中再乘
                applyPseudoImpulse(c, c.m_normal * applied);
            }
        }
    }

    // 4. 使用位置更新
    for (RigidActor* actor : actors) {
        DynamicRigidBody* body = actor->AsDynamic();
        if (body == nullptr) {
            continue;
        }

        if (body->m_pseudo_linear.isZero() && body->m_pseudo_angular.isZero()) {
            continue;
        }

        Transform trans = body->GetTransform();
        trans.m_position += body->m_pseudo_linear * dt;

        const Vector3 omega_dt = body->m_pseudo_angular * dt;
        const real angle = omega_dt.norm();
        if (angle > kREAL_EPSILON) {
            const Vector3 axis = omega_dt / angle;
            const Quaternion dq(Eigen::AngleAxis<real>(angle, axis));
            trans.m_rotation = (dq * trans.m_rotation).normalized();
        }

        body->Teleport(trans);

        body->m_pseudo_linear.setZero();
        body->m_pseudo_angular.setZero();
    }
}
```

这里是每次累加$lambda$到$\Delta \pmb q$上，最后使用总的$\Delta \pmb q$进行位移修正。
