## Geometry, Shape和RigidActor

首先是一些最基本的结构的定义。

### Geometry

`Geometry`是几何体，其派生类是各种各样的具体的几何：

```cpp
// 为了效率，没有定义虚的析构函数，所以永远不要从Geometry*去释放内存。
class Geometry {
public:
    enum class Type {
        Invalid = -1,
        Box,
        Sphere,
        Capsule,
        Cylinder,
        ConvexHull,

        kCount,
    };

    explicit Geometry(Type type);

    [[nodiscard]] Type GetType() const;

    [[nodiscard]] BoxGeometry* AsBox();
    [[nodiscard]] SphereGeometry* AsSphere();
    [[nodiscard]] CapsuleGeometry* AsCapsule();
    [[nodiscard]] CylinderGeometry* AsCylinder();
    [[nodiscard]] ConvexHullGeometry* AsConvexHull();

    [[nodiscard]] const BoxGeometry* AsBox() const;
    [[nodiscard]] const SphereGeometry* AsSphere() const;
    [[nodiscard]] const CapsuleGeometry* AsCapsule() const;
    [[nodiscard]] const CylinderGeometry* AsCylinder() const;
    [[nodiscard]] const ConvexHullGeometry* AsConvexHull() const;

private:
    Type m_type;
};

// 一个traits，用于标识哪些类型的几何体只能是Static的（比如未来可能要加的三角面，高度图）
template <Geometry::Type>
struct GeometryTraits {
    constexpr static bool MustBeStatic = false;
};
```

然后有一个`GeometryUnion`用来将所有的几何体存储在一起（抄的PhysX），以避免独立`Geometry`的内存分配：

```cpp
class GeometryUnion {
public:
    GeometryUnion() = default;
    explicit GeometryUnion(Geometry::Type type);

    explicit GeometryUnion(const BoxGeometry& box);
    explicit GeometryUnion(const SphereGeometry& sphere);
    explicit GeometryUnion(const CapsuleGeometry& capsule);
    explicit GeometryUnion(const CylinderGeometry& cylinder);
    explicit GeometryUnion(const ConvexHullGeometry& convex_hull);

    [[nodiscard]] bool IsValid() const;

    [[nodiscard]] const BoxGeometry* AsBox() const;
    [[nodiscard]] BoxGeometry* AsBox();

    [[nodiscard]] const SphereGeometry* AsSphere() const;
    [[nodiscard]] SphereGeometry* AsSphere();

    [[nodiscard]] const CapsuleGeometry* AsCapsule() const;
    [[nodiscard]] CapsuleGeometry* AsCapsule();

    [[nodiscard]] const CylinderGeometry* AsCylinder() const;
    [[nodiscard]] CylinderGeometry* AsCylinder();

    [[nodiscard]] const ConvexHullGeometry* AsConvexHull() const;
    [[nodiscard]] ConvexHullGeometry* AsConvexHull();

    [[nodiscard]] const Geometry* GetGeometry() const;
    [[nodiscard]] Geometry* GetGeometry();

private:
    template <typename T>
    static constexpr bool IsGeomSatisfied = std::is_trivially_destructible_v<T>;

    static_assert(IsGeomSatisfied<InvalidGeometry>);
    static_assert(IsGeomSatisfied<BoxGeometry>);
    static_assert(IsGeomSatisfied<SphereGeometry>);
    static_assert(IsGeomSatisfied<CapsuleGeometry>);
    static_assert(IsGeomSatisfied<CylinderGeometry>);
    static_assert(IsGeomSatisfied<ConvexHullGeometry>);

	// 将他们都变成Union，这样一个GeometryUnion就可以存储任意几何体，而不需要从内存中分分配
    union {
        InvalidGeometry m_invalid{};
        BoxGeometry m_box;
        SphereGeometry m_sphere;
        CylinderGeometry m_cylinder;
        CapsuleGeometry m_capsule;
        ConvexHullGeometry m_convex_hull;
    } m_union;
};
```

### Shape

形状，是用于附加在刚体上的形状。**所有碰撞相关的东西都应该放在Shape中**。比如几何体，摩擦因子，弹性系数等。但模拟相关的东西（比如速度，加速度，力等）则不应该放在这里。

```cpp
class Shape {
public:
    friend class BroadPhase;
    friend class RigidActor;

    Shape();
    explicit Shape(const BoxGeometry& box);
    explicit Shape(const SphereGeometry& sphere);
    explicit Shape(const CapsuleGeometry& capsule);
    explicit Shape(const CylinderGeometry& cylinder);
    explicit Shape(const ConvexHullGeometry& convex_hull);

    [[nodiscard]] Geometry::Type GetType() const;

    void SetLocalTransform(const Transform& transform);
    void SetLocalTransform(Vector3 position, Quaternion rotation);

    [[nodiscard]] const Transform& GetLocalTransform() const;
    [[nodiscard]] const Transform& GetTransform() const;
    [[nodiscard]] const BoundingBox& GetBoundingBox() const;

    [[nodiscard]] MassProperties ComputeMassProperties(real density) const;

    RigidActor* GetOwner();
    [[nodiscard]] const RigidActor* GetOwner() const;

private:
    void rebuildBV();
    void attachToActor(RigidActor* actor);
    void updateByOwnerTransform();

    GeometryUnion m_geometry;      // 存储一个几何体
    Transform m_local_transform;   // 相对于刚体质心的局部偏移
    Transform m_transform;         // 全局坐标
    BoundingBox m_aabb;            // AABB，用于BroadPhase加速
	real m_friction{0.2};          // 摩擦因子。未来可能会换成基于材质的摩擦
	real m_density{1.0};           // 密度，用于后面计算惯性张量

    Vector3 m_inv_inertia;         // 
	RigidActor* m_owner{};    // 持有他的刚体
};
```

### RigidActor

`RigidActor`是刚体的基类，而`DynamicRigidBody`和`StaticRigidBody`则是他的子类。

**所有模拟相关的东西都应该放在这里**，比如速度，角速度，力，力矩，惯性张量等。

有些引擎（如JoltPhysics）会将静态/动态物体都放在一个类里面，但是静态物显然不需要动态物中的速度，力，质量，惯性等用于模拟的属性，所以我们这里为了节省内存还是分开放。

```cpp
class RigidActor {
public:
    enum class Type {
        Dynamic,
        Static,
    };

    explicit RigidActor(Type type);
    virtual ~RigidActor() = default;

    [[nodiscard]] DynamicRigidBody* AsDynamic();
    [[nodiscard]] StaticRigidBody* AsStatic();

    [[nodiscard]] const DynamicRigidBody* AsDynamic() const;
    [[nodiscard]] const StaticRigidBody* AsStatic() const;

    [[nodiscard]] Type GetType() const;

    virtual void Teleport(const Transform& transform);
    [[nodiscard]] const Transform& GetTransform() const;

    [[nodiscard]] std::span<Shape*> GetShapes();

    void AttachShape(Shape& shape);
    void RemoveShape(Shape& shape);
    void RemoveShape(size_t index);

    void SetFriction(real);
    [[nodiscard]] real GetFriction() const;

protected:
    Transform m_transform;        // 质心。虽然有些引擎中会定义额外的质心偏移量，
                                  // 但我们这里就不写那么麻烦了，
                                  // 我们认为刚体质心就是刚体位置
    std::vector<Shape*> m_shapes;
    Type m_type;
};

// 动态物需要有模拟相关的参数
class DynamicRigidBody : public RigidActor {
public:
    DynamicRigidBody();

    [[nodiscard]] real GetMass() const;
    void SetMass(real mass);

    [[nodiscard]] Vector3 GetVelocity() const;
    [[nodiscard]] Vector3 GetAngularVelocity() const;
    [[nodiscard]] Vector3 GetImpulse() const;

private:
    real m_inv_mass{1};

    Vector3 m_velocity{Vector3::Zero()};         // 线速度
    Vector3 m_angular_velocity{Vector3::Zero()}; // 角速度

    Vector3 m_inv_inertia{Vector3::Zero()};      // 主轴下的转动惯量
    Quaternion m_inertia_rotation{
        Quaternion::Identity()};  // 主轴到刚体局部坐标下的旋转

    Vector3 m_force{Vector3::Zero()};  // 力
    Vector3 m_torque{Vector3::Zero()}; // 力矩
};

// 静态物没有多的东西
class StaticRigidBody : public RigidActor {
public:
    StaticRigidBody();
};

```

## 刚体的惯性张量计算方案

根据经典力学，我们知道，如果刚体的形状不变，那么惯性张量在惯性主轴下有两个优点：

1. 不变
2. 是对角矩阵

此时可以使用一个`Vector3 m_inertia`来记录而不是一个`Matrix33`。

如果你的物理引擎中，一个刚体只有一个形状，且此形状的质心总是在形状中心，那么你可以直接这样存。但是一般物理引擎中，质心并不总是在`Shape`中心，甚至一个刚体可能有多个`Shape`。这个时候必须汇集所有`Shape`自己的惯性张量来算出整个`DynamicRigidBody`的惯性张量。

步骤如下：

1. 对于每个`Shape`，计算其在主轴下的，质心位于几何中心的惯性张量（主惯性矩），此时是一个对角矩阵，使用`Vector3`存储
2. 用`Shape`的`local_transform`将质心和惯性张量变换到刚体局部坐标系下
3. 用所有`Shape`的质量和质心，算出整个刚体的质心
4. 用**平行轴定理**，把每个`Shape`的惯性张量移到刚体质心，然后对其求和得到整体惯性张量
5. 对惯性张量做分解，得到惯性主轴以及主轴下的惯性张量。以及如何从刚体局部坐标系转到主坐标系的旋转。
### 主惯性张量计算

第一步是最好做的，首先计算主轴下的惯性张量。不同的几何体物理上有现成的公式：

| 形状                                                     | 质量                                       | 主惯性矩                                                                                                                                                                   |
| ------------------------------------------------------ | ---------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Box                                                    | $8\rho h_x h_y h_z$                      | $\begin{aligned} x &= \frac{m}{3}(h_y^2 + h_z^2)\\ y &= \frac{m}{3}(h_x^2 + h_z^2)\\ z &= \frac{m}{3}(h_x^2 + h_y^2) \end{aligned}$                                    |
| Sphere                                                 | $\frac{4}{3}\pi r^3 \rho$                | $x,y,z=\frac{2}{5}mr^2$                                                                                                                                                |
| Cylinder（轴线在$y$轴上，$H$是圆柱高度）                            | $\pi r^2H\rho$                           | $\begin{aligned} y &= \frac{1}{2}(mr^2)\\ x,z &= \frac{m}{12}(3r^2+H^2)\end{aligned}$                                                                                  |
| Causple（轴线在$y$轴上，$H$是圆柱部分高度，$m_c$是圆柱部分质量，$m_h$是半球部分质量） | $\pi r^2H\rho + \frac{4}{3}\pi r^2 \rho$ | $\begin{aligned} y&=\frac{1}{2}m_cr^2+\frac{4}{5}m_hr^2 \\ x,z&=\frac{1}{12}m_c(3r^2+H^2)+\frac{4}{5}m_hr^2+m_h\left(\frac{1}{2}H^2+\frac{3}{4}Hr\right)\end{aligned}$ |
这里`ConvexHull`要麻烦一些，其质量需要先得到几何中心$P_c = \frac{\sum_{i = 1}^N P_i}{N}$，然后通过此中心和每个面上的三角面构成的四面体的体积$V_i$进行求和。这里假设四面体的三个边向量是$\pmb{a}, \pmb{b}, \pmb{c}$，那么四面体的体积是：

$$
V_i = \frac{1}{6}\pmb{a}\cdot (\pmb{b} \times \pmb{c})
$$

然后每个四面的对质心的贡献是

$$
S_t = V_t \frac{\pmb a + \pmb b + \pmb c}{4}
$$
这样质心就是：

$$
C = \frac{\sum S_t}{\sum V_t}
$$
惯性张量则更麻烦，先定义某个三角面中的三个点$P_1, P_2, P_3$和质心$C$构成的向量：

$$
\mathbf a=P_1-C,\qquad
\mathbf b=P_2-C,\qquad
\mathbf c=P_3-C
$$

然后计算二阶矩：

$$
M_C = \sum_t \frac{V_t}{20}
\left(
\mathbf a\mathbf a^T +
\mathbf b\mathbf b^T +
\mathbf c\mathbf c^T +
(\mathbf a+\mathbf b+\mathbf c)
(\mathbf a+\mathbf b+\mathbf c)^T
\right)
$$

然后得到绕质心的惯性张量：

$$
\begin{aligned}
I_C
&=
\rho\left(
\operatorname{tr}(M_C)I_3-M_C
\right) \\
I_3 &= \operatorname{diag}(1, 1, 1) \\
\end{aligned}
$$

这里注意：**ConvexHull的几何中心不一定在Shape的`local_transform`处，他是有偏移的**，所以你需要将偏移量也一并返回出去。一般的计算接口是：

```cpp
struct GeometryMassProperties {
    real m_mass{0}; // 质量
    Vector3 m_center_of_mass{Vector3::Zero()}; // 质心到Shape的local_transform的偏移量，只有ConvexHull不是0
    Vector3 m_inertia{Vector3::Zero()}; // 主轴下的转动惯量
    std::array<Vector3> m_principal_axes; //
};

class Shape {
	[[nodiscard]] GeometryMassProperties ComputeMassProperties(real density) const;
};
```

### 将质心和主惯性张量移到刚体局部坐标系下

对于质心，只需要将其做一次变换。对于主轴，只需做一次旋转（主轴存在`Matrix33`的各列中）。而对于惯性张量，则需要

$$
I_{body} = 
A_{body}
\begin{bmatrix}
I_x & 0 & 0 \\
0 & I_y & 0 \\
0 & 0 & I_z \\
\end{bmatrix}
A_{body}^T
$$
其中$A_{body}$是主轴在Shape Space下的坐标。也就是变换后的主轴所在矩阵。

```cpp
// Step2: transform inertia & center of mass from geometry space to
// shape space
const Transform& shape_local_trans = shape->GetLocalTransform();
const Matrix33 R = shape_local_trans.m_rotation.toRotationMatrix();
const Vector3 t = shape_local_trans.m_position;

Vector3 center_of_mass = t + R * mp.m_center_of_mass;

Matrix33 principal_axes = R * mp.m_principle_axes;

Matrix33 inertia_body = principal_axes * mp.m_inertia.asDiagonal() *
						principal_axes.transpose();
```

### 求出刚体质心

只需要对所有`Shape`的质心按质量加权平均即可：

$$
c_{body} = \frac{\sum m_ic_i}{\sum m_i}
$$
### 将每个`Shape`的惯性张量移到刚体质心并求和

使用平行轴定理：

$$
I^{'} = I + M(||\pmb{d}||^2 \pmb{E}_3 - \pmb{d}\pmb{d}^T)
$$
```cpp
// Step4: using `parallel axis theorem`
// to move inertia from shape space to rigidbody space
Matrix33 body_inertia = Matrix33::Zero();
for (auto& mp : shape_mp_list) {
	const Vector3 d = mp.m_center_of_mass - rigid_center_of_mass;

	const Matrix33 shift =
		Matrix33::Identity() * d.squaredNorm() - d * d.transpose();

	body_inertia += mp.m_inertia + mp.m_mass * shift;
}
```

### 分解刚体的惯性张量

最后就是分解惯性张量为特征向量和特征值。这里我直接用`Eigen`库的分解函数了：

```cpp
// Step5: get eigen values & eigen vectors
// NOTE: SelfAdjointEigenSolver use to decompose symmetric matrix,
//       faster than EigenSolver
Eigen::SelfAdjointEigenSolver<Matrix33> solver(body_inertia);

if (solver.info() != Eigen::Success) {
	return {};
}

Vector3 principal_inertia = solver.eigenvalues();
Matrix33 principal_axes = solver.eigenvectors();

// 浮点数误差可能导致某个分量小于0，必须强制大于0不然物理上不正确
principal_inertia = principal_inertia.cwiseMax(0);

// 由于我希望旋转矩阵可以转换成四元数，所以必须强制旋转矩阵为右手系
if (principal_axes.determinant() < 0) {
	principal_axes.col(2) = -principal_axes.col(2);
}

// 转换成四元数
auto inertia_rotation = Quaternion(principal_axes).normalized();
```

## 物理模型的实现

接下来编写模拟求解器：

```cpp
class RigidSolver {
public:
    void Solve(Manifold& manifold);
    ...
};
```

求解器要求传入一个`Manifold`，并求解此`Manifold`内的一对物体的碰撞分离约束。

### 速度积分

首先根据当前的力做速度积分。这里是公式（41）的变体：

$$
\begin{aligned}
& M\bigl(\pmb u^{(k+1)}-\pmb u^{(k)}\bigr)
={}^{u}J_n^{\mathsf T}{}^{u}\pmb p_n^{(k+1)}
+{}^{u}J_f^{\mathsf T}{}^{u}D\,{}^{u}\pmb\alpha
+{}^{b}J_n^{\mathsf T}{}^{b}\pmb p_n^{(k+1)}
+{}^{b}J_f^{\mathsf T}{}^{b}D\,{}^{b}\pmb\alpha
+\pmb p_{ext}^{(k)} \\
&\Rightarrow \\
& \pmb u^{(k+1)}-\pmb u^{(k)} 
=M^{-1}\ {}^{u}J_n^{\mathsf T}{}^{u}\pmb p_n^{(k+1)}
+M^{-1}\ {}^{u}J_f^{\mathsf T}{}^{u}D\,{}^{u}\pmb\alpha
+M^{-1}\ {}^{b}J_n^{\mathsf T}{}^{b}\pmb p_n^{(k+1)}
+M^{-1}\ {}^{b}J_f^{\mathsf T}{}^{b}D\,{}^{b}\pmb\alpha
+M^{-1}\ \pmb p_{ext}^{(k)} \\
&\Rightarrow \\
& \pmb u^{(k+1)} = \pmb u^{(k)} + \pmb{o}
+M^{-1}\ \pmb p_{ext}^{(k)} \\
&\text{其中} \pmb{o} =
M^{-1}\ {}^{u}J_n^{\mathsf T}{}^{u}\pmb p_n^{(k+1)}
+M^{-1}\ {}^{u}J_f^{\mathsf T}{}^{u}D\,{}^{u}\pmb\alpha
+M^{-1}\ {}^{b}J_n^{\mathsf T}{}^{b}\pmb p_n^{(k+1)}
+M^{-1}\ {}^{b}J_f^{\mathsf T}{}^{b}D\,{}^{b}\pmb\alpha
\end{aligned}
$$
这里只是将左边的质量矩阵挪到右边，然后变成一个$\pmb{u}$的增量形式。

我们使用的是**倒数第二个式子中后面的部分**，即$\pmb{u}^{(k+1}) = \pmb{u}^{(k)} + M^{-1} \pmb{p}_{ext}^{(k)}$。至于$\pmb{o}$，我们等到后面算。

这里$\pmb{p}_{ext}^{(k)}$就是这一步的总外力产生的动量。这里其实有一些工程上的取舍，按道理我们整个物理模型里面所有的力都被动量替换了，理论上不应该有力。但是从用户使用物理引擎的角度上来说，他们可能更希望给一个力而不是动量。所以我们`DynamicRigidBody`类里面存的是力/力矩而不是动量。

市面上的物理引擎允许用户给一个冲量。有些是两者都可以给（比如PhysX）。

这里使用（15）式中对$\pmb{p}_{ext}^{(k)}$的定义，将矩阵拆开，得到速度和角速度的计算公式：

$$
\begin{aligned}
\pmb{u}_{linear} &= \frac{\pmb{F}}{m}\Delta t \\
\pmb{I}\pmb{u}_{angular} &= \pmb{\tau} - \pmb{\omega} \times \pmb{I}\pmb{\omega}
\end{aligned}
$$
这里线速度就是牛顿第二定律的变形，可以直接写码。而第二项还得进行变形才能得到角速度：

$$
\pmb{u} = \pmb{I}^{-1}\pmb{\tau} - \pmb{I}^{-1}(\pmb{\omega} \times \pmb{I}\pmb{\omega})
$$

这里又迎来一个工程上的取舍，就是后面的陀螺项$\pmb \omega \times \pmb I \pmb \omega$到底要不要算？

计算陀螺项会带来如下问题：

* 会给系统注入额外的能量，即使使用辛积分也无法避免（TODO:弄清楚为何无法避免）。这导致旋转的物体会越转越快，最后爆炸
* 在基于约束的物理模型中，陀螺项常常会破坏约束求解器

而陀螺项带来的效应一般只在如下场合才比较明显：

* 物体非对称。此时陀螺项非0
* 物体高速转动时

所以如果你只是模拟一些刚体，那根本不需要加入陀螺项。如果你要模拟陀螺，飞盘等你就需要这一项。

对于常见的球体高速滚动，由于其各向同性的性质，其陀螺项无论如何都为0，所以也不需要模拟。

综上所述，在去掉陀螺项的情况下，我们只需这样更新角速度：

$$
\pmb u^{(k+1)} = \pmb u^{(k)} + \pmb I^{-1}\pmb \tau
$$
那么在无陀螺项时，所有的代码为：

```cpp
void RigidSolver::integrateVelocity(DynamicRigidBody& body, real dt) const {
    Vector3 velocity = body.GetVelocity();
    Vector3 angular_velocity = body.GetAngularVelocity();

    velocity += body.GetForce() * body.GetMassProperties().m_inv_mass * dt;
    angular_velocity += body.MultiplyInvInertiaWorld(body.GetTorque() * dt);

    body.SetVelocity(velocity);
    body.SetAngularVelocity(angular_velocity);
}
```

这里`MultiplyInvInertiaWorld`是一个小函数，用来将参数$v$计算$\pmb I^{-1} v$公式并返回。因为这个公式会在很多地方使用所以封装了一下。注意这里$\pmb I$是**世界坐标下的惯性张量**，每次计算时都新算（因为$\pmb I$和刚体位置&速度强相关，动了一点点都得重算，就不做cache了）。

如果非要算陀螺项，需要注意牛顿-欧拉方程是在主轴下定义的，所以得在主轴坐标系下计算。需要在增量完速度&角速度后面加上如下代码：

```cpp
if (use_gyro) {
	auto& mp = body.GetMassProperties();
	
	// 得到变换到主轴坐标系下的矩阵
	Quaternion q = body.GetTransform().m_rotation * mp.m_inertia_rotation;

	// 将角速度变换到主轴下
	Vector3 local_w = q.conjugate() * angular_velocity;

	// 得到inertia。因为存的都是inertia的倒数所以要转换
	Vector3 local_inertia;
	for (int i = 0; i < 3; i++) {
		real inv_inertia = mp.m_inv_inertia[i];
		local_inertia[i] = inv_inertia > 0 ? 1.0 / inv_inertia : 0;
	}

	// 算主轴下的角动量 L = Iw
	Vector3 local_L = local_inertia.cwiseProduct(local_w);
	
	// 陀螺项，这是用无外力的牛顿-欧拉方程
	Vector3 new_L = local_L - local_w.cross(local_L) * dt;

	// 归一化L，因为无外力矩时L守恒，但欧拉积分会放大他，所以要归一化，不然越转越快
	real old_len2 = local_L.squaredNorm();
	real new_len2 = new_L.squaredNorm();
	if (new_len2 > 0) {
		new_L *= std::sqrt(old_len2 / new_len2);
	}
	
	// 转回世界坐标系
	angular_velocity = q * mp.m_inv_inertia.cwiseProduct(new_L);
}
```

这里的陀螺项`new_L`的计算，是用牛顿欧拉方程中去掉力矩的结果$\frac{d\pmb L}{dt} = -\pmb \omega \times \pmb I \pmb \omega$（因为力矩造成的影响在前面算过了）。

归一化$\pmb L$则是为了防止积分算法额外注入的能量导致物体越转越快，$\pmb L$方向是对的，但是大小会越来越大，所以强制将他的长度改回计算之前的长度，保持长度恒定。

### 碰撞检测和流型生成

这里直接调用上一个文章中说的流型生成函数即可（这里我暂时没用空间划分，以让代码更加直观），将所有流型都存下来以便后续解算：

```cpp
void RigidSolver::detectContacts(std::span<RigidActor*> actors, real dt) {
    for (size_t i = 0; i < actors.size(); i++) {
        for (size_t j = i + 1; j < actors.size(); j++) {
            RigidActor* actor1 = actors[i];
            RigidActor* actor2 = actors[j];
            if (actor1->GetType() == RigidActor::Type::Static &&
                actor2->GetType() == RigidActor::Type::Static) {
                continue;
            }

            for (Shape* shape1 : actor1->GetShapes()) {
                for (Shape* shape2 : actor2->GetShapes()) {
                    if (!shape1->GetBoundingBox().IsIntersect(
                            shape2->GetBoundingBox())) {
                        continue;
                    }

                    Manifold manifold;
                    if (!ComputeManifold(*shape1, *shape2, &manifold)) {
                        continue;
                    }
                    
                    // 转换成SolverContact并存下来（下面会说）
					convertManifoldToSolverContacts(manifold, dt)
                }
            }
        }
    }
}
```

### 将流型转换成解算器接触

我们这里定义解算器使用的接触`SolverContact`。里面只是预计算一些常数，并且将`Manifold`的信息汇总在一起：

```cpp
struct SolverContact {
    RigidActor* m_body1{};
    RigidActor* m_body2{};

    // 只是m_body1,m_body2的对应动态物
    DynamicRigidBody* m_dyn1{};
    DynamicRigidBody* m_dyn2{};

    // 接触点到质心的向量，用于力矩计算
    Vector3 m_r1{Vector3::Zero()};
    Vector3 m_r2{Vector3::Zero()};

	// 此接触点处的局部坐标系
    Vector3 m_normal{Vector3::Zero()};
    Vector3 m_tangent1{Vector3::Zero()};
    Vector3 m_tangent2{Vector3::Zero()};

	real m_depth{0};     // 接触深度
    real m_friction{0};  // 摩擦系数

    real m_normal_mass{0};
    real m_tangent1_mass{0};
    real m_tangent2_mass{0};
    
    // JM^{-1}J^T 对角矩阵
    real m_normal_mass{0};
    std::array<real, 2> m_tangent_masses{0};

    // LCP中要求解的量: p_n, p_f
    real m_normal_impulse{0};
    std::array<real, 2> m_tangent_impulses{0};

    // -C_n/dt
    real m_bias{0};
};
```

这里的`m_normal`,`m_tangent1`,`m_tangent2`，是在接触点处，以穿透方向为$z$轴，搭建的一个直角坐标系：

```cpp
contact.m_normal = manifold.m_separate_normal.normalized();
contact.m_tangent1 = contact.m_normal.unitOrthogonal();
contact.m_tangent2 =
contact.m_normal.cross(contact.m_tangent1).normalized();
```

这里`unitOrghogonal()`函数随意返回一个和`m_normal`垂直的向量，实现上是挑一个`m_normal`中最大分量所在的方向和`m_normal`做叉乘。

这个坐标系其实就是我们介绍库伦摩擦时的坐标系，建立此坐标系也有利于后面的库伦摩擦计算。

---

然后要解释约束雅克比矩阵$\pmb J$的计算：

$$
\pmb J = \frac{\partial \dot{C}}{\partial \pmb u}
$$
对于接触约束来说，$C$是：

$$
C = \pmb n \cdot(\pmb x_2 + \pmb r_2 - (\pmb x_1 + \pmb r_1))
$$
这里$\pmb x_i$是第$i$个刚体的质心位置，$\pmb r_i$是接触点相对质心的位置（即代码中的`m_r1`,`m_r2`）。这个约束在值上应该是穿透深度：

![接触约束](/assets/从0开始编写物理引擎/接触约束.png)

图上紫色的是质心，绿色和红色是一对接触点，灰色向量就是$\pmb x_i + \pmb r_i$。所以他两相减再点乘$\pmb n$就是穿透深度。

这里首先让$C$对时间求导，得到：

$$
\begin{aligned}
\dot{C} &= \pmb n \cdot (\pmb v_{p1} - \pmb v_{p2}) \\
&= \pmb n \cdot [\pmb v_2 + \pmb \omega_2 \times \pmb r_2 - (\pmb v_1 + \pmb \omega_1 \times \pmb r_1)] \\
&= \pmb n  \cdot \pmb v_2 + \pmb n  \cdot \pmb \omega_2 \times \pmb r_2 - (\pmb n \cdot \pmb v_1 + \pmb n \cdot \pmb \omega_1 \times \pmb r_1)] \\
\end{aligned}
$$
这里$\pmb v_{p1}, \pmb v_{p2}$是接触点处的速度。

然后对$\pmb n \cdot \pmb \omega_i \times \pmb r_i$做向量三重积恒等式$a \cdot (b \times c) = b \cdot (c \times a)$的交换，就有$\pmb \omega_i \cdot(\pmb r_i \times \pmb n)$。

然后需要对广义速度求导，这里广义速度为$\pmb u = [\pmb v_1, \pmb \omega_1, \pmb v_2, \pmb \omega_2]$，就有：

$$
\pmb J = \frac{\partial \dot{C}}{\partial \pmb u} = 
\begin{bmatrix}
-\pmb n^T & -(\pmb r_1 \times \pmb n)^T & n^T & (\pmb{r}_2 \times \pmb n)^T
\end{bmatrix}
$$
接下来计算$\pmb J M^{-1}\pmb J^T$（见（53c）式），这里$M^{-1}$是：

$$
M^{-1} = 
\begin{bmatrix}
\frac{1}{m_1} \pmb 1 & 0 & 0 & 0 \\
0 & \pmb I_1^{-1} & 0 & 0 \\
0 & 0 & \frac{1}{m_2}\pmb 1 & 0 \\
0 &  0 & 0 & \pmb I_2^{-1} \\
\end{bmatrix}
$$
将其放入$\pmb J M^{-1} \pmb J^T$并拆开，得到：

$$
\frac{1}{m_1} + \frac{1}{m_2} +
(\pmb r_1 \times \pmb n)^T \pmb I_1^{-1} (\pmb r_1 \times \pmb n) +
(\pmb r_2 \times \pmb n)^T \pmb I_2^{-1} (\pmb r_2 \times \pmb n)
$$
对应代码就是（代码里的$k$）：

```cpp
real RigidSolver::computeEffectiveMass(const SolverContact& contact,
                                       Vector3 dir) const {
    real k = 0;

    if (contact.m_dyn1) {
        Vector3 rn = contact.m_r1.cross(dir);
        k += contact.m_dyn1->GetMassProperties().m_inv_mass +
            rn.dot(contact.m_dyn1->MultiplyInvInertiaWorld(rn));
    }

    if (contact.m_dyn2) {
        Vector3 rn = contact.m_r2.cross(dir);
        k += contact.m_dyn2->GetMassProperties().m_inv_mass +
            rn.dot(contact.m_dyn2->MultiplyInvInertiaWorld(rn));
    }

    return k > 0 ? 1 / k : 0;
}
```

这里`dir`是$\pmb n$，$\pmb r \times \pmb n$是`rn`。最后返回的是$\frac{1}{\pmb{JM^{-1}J^T}}$，取倒数是为了方便后面计算。

那么为什么需要往`dir`投影呢？因为式（51）中的$A$矩阵中的$\pmb J_n, \pmb J_D$。这里$\pmb D$本来是摩擦锥近似的多面体的棱的方向，而我们这里用的是盒体近似摩擦锥，所以$\pmb D$就只有两个切向方向。而$\pmb J_D = \pmb D^T \pmb J_f$，也就是将$\pmb J_f$往切向方向的投影。而再看$A$矩阵中的前$3 \times 3$矩阵，将关节约束删掉后为：

$$
A = 
\begin{bmatrix}
\pmb J_n M^{-1} \pmb J_n^{\mathsf T} & \pmb J_nM^{-1}\pmb J_D^{\mathsf T} & 0 \\
\pmb J_D M^{-1} \pmb J_n^{\mathsf T} & \pmb J_DM^{-1}\pmb J_D^{\mathsf T} & {}^u\pmb E \\
\phantom{}{}^u \pmb U & \pmb -{}^u\pmb E^{\mathsf T} & 0 \\
\end{bmatrix}
$$
观察其对角元素，为：

$$
\pmb J M^{-1} \pmb J^{\mathsf T} + 
(\pmb J M^{-1} \pmb J^{\mathsf T})\,B^{-1}(\pmb J M^{-1} \pmb J^{\mathsf T})
$$
你可以看到有许多$\pmb J M^{-1} \pmb J^{\mathbf T}$，这就是我们要预先算$\pmb J M^{-1} \pmb J^{\mathsf T}$的原因。

对应代码就是：

```cpp
contact.m_normal_mass = computeEffectiveMass(contact, contact.m_normal);
contact.m_tangent_masses[0] = computeEffectiveMass(contact, contact.m_tangent1);
contact.m_tangent_masses[1] = computeEffectiveMass(contact, contact.m_tangent2);

```

---

然后是`SolverContact::m_bias`的计算。这个对应的是（44）式里面的 $\frac{\partial C_n}{\Delta t}$。这个也是后面要用所以预计算。
### 约束求解

接下来进行约束求解。

#### 接触约束

需要求解$\pmb p_n$，根据（51）式，他是$A$的第一行乘$\pmb x$等于$\pmb b_1$：

$$
A_{11} \pmb p_n + A_{12}\pmb {}^u \pmb \alpha + \pmb b_1 = 0
$$

注意关节约束被删了所以没有${}^b\pmb \alpha$。那么$\pmb p_n$就是：

$$
\pmb p_n = -\frac{\pmb b_1 + A_{12}{}^u \pmb \alpha}{A_{11}}
$$
展开得到：

$$
\pmb p_n = -\frac{(\pmb J_n \pmb r + \frac{C_n}{\Delta t}) + (\pmb J_n M^{-1} \pmb J_D^T)\pmb \alpha}{A_{11}} 
$$
注意原式中$\pmb S_{11}$中由于没有关节约束，所有${}^b \pmb J_n$都是0，所以只剩$M^{-1}$。

这里$\pmb{\alpha} = (\alpha_{i1}, \alpha_{i2}, \cdots, \alpha_{in})$是乘了摩擦锥半径的重心坐标，是摩擦冲量在摩擦多边形顶点方向上的权重。但我们不需要真的使用他，因为我们使用的是盒子摩擦模型，表示摩擦冲量只需要两个元素$\pmb p_t, \pmb p_o$，然后只需将其`clamp`到$[-\mu \pmb p_n, \mu \pmb p_n]$即可。如果用重心坐标$\pmb \alpha$的话，他得有4个元素（盒子四个顶点），解起来很麻烦。

那这里的$\pmb J_D$就使用盒子的切基向量表示：

$$
\pmb J_D = 
\begin{bmatrix}
\pmb J_t \\
-\pmb J_t \\
\pmb J_o \\
-\pmb J_o
\end{bmatrix}
$$

其中

$$
\begin{aligned}
\pmb J_t &= 
\begin{bmatrix}
-\pmb t^T & -(\pmb r_1 \times \pmb t)^T & \pmb t^T & (\pmb r_2 \times \pmb t)^T
\end{bmatrix} \\
\pmb J_o &= 
\begin{bmatrix}
-\pmb o^T & -(\pmb r_1 \times \pmb o)^T & \pmb o^T & (\pmb r_2 \times \pmb o)^T
\end{bmatrix} \\
\end{aligned}
$$

其实就和之前求$\pmb J M^{-1} \pmb J^T$中的$\pmb J$一样，只是方向不同。

然后：

$$
\pmb J_D^{\mathsf T} \pmb \alpha = J_t^T \pmb \alpha_1 - J_t^T \pmb \alpha_2 + J_o^T \pmb \alpha_3 - J_o^T \pmb \alpha_4 = J_t^T(\pmb \alpha_1 - \pmb \alpha_2) + J_o^T(\pmb \alpha_3 - \pmb \alpha_4)
$$
这里$\pmb \alpha_1 - \pmb \alpha_2$就是$\pmb p_t$。而另一个就是$\pmb p_o$，即：

$$
\pmb J_D^{\mathsf T} \pmb \alpha = J_t^T \pmb p_t + J_o^T \pmb p_o
$$

那这样对$(\pmb J_n M^{-1} \pmb J_D)\pmb \alpha$展开得到：

$$
\pmb J_n M^{-1} \pmb J_t^T \pmb p_t + \pmb J_n M^{-1} \pmb J_o^T \pmb p_o
$$
现在分子左边还有$\pmb J_n \pmb r$，将$\pmb r$展开并略去双边约束相关变量，得到：

$$
\pmb r = \pmb u^{(k)} + M^{-1}\pmb{p}_{ext}
$$

再回顾一下$\pmb u^{(k+1)}$的式子：

$$
\begin{aligned}
& \pmb u^{(k+1)} = \pmb u^{(k)} + \pmb{o}
+M^{-1}\ \pmb p_{ext}^{(k)} \\
&\text{其中} \pmb{o} =
M^{-1}\ {}^{u}J_n^{\mathsf T}{}^{u}\pmb p_n^{(k+1)}
+M^{-1}\ {}^{u}J_f^{\mathsf T}{}^{u}D\,{}^{u}\pmb\alpha
+M^{-1}\ {}^{b}J_n^{\mathsf T}{}^{b}\pmb p_n^{(k+1)}
+M^{-1}\ {}^{b}J_f^{\mathsf T}{}^{b}D\,{}^{b}\pmb\alpha
\end{aligned}
$$
可以看到$\pmb r = \pmb u^{(k+1)} - \pmb o$。这里$D \pmb \alpha = \pmb p_t + \pmb p_o$，那么

$$
\begin{aligned}
\pmb J_n \pmb r &= \pmb J_n \pmb u^{(k+1)} - \pmb J_n \pmb o \\
&= \pmb J_n \pmb u^{(k+1)} - \pmb J_n M^{-1}J_n^{\mathsf T}\pmb p_n^{(k+1)} -
\pmb J_n M^{-1}J_t^{\mathsf T}\pmb p_t -
\pmb J_n M^{-1}J_o^{\mathsf T}\pmb p_o  \\
\end{aligned}
$$

将$\pmb J_n \pmb r$代回原式：

$$
\pmb p_n^{(k+1)} = \pmb p_n^{(k+1)} -\frac{\pmb J_n\pmb u^{(k+1)} + \frac{C_n}{\Delta t}}{A_{11}}
$$
这里注意，不能将两边的$\pmb p_n$消掉，这里的$k+1$不是PGS里的迭代次数，而是整个Solver进行Step的次数。我们现在是在PGS内部对当前$\pmb p_n^{(k+1)}$进行求解，所以这里的理解是使用PGS迭代地去解$\pmb p_n^{(k+1)}$，这个式子在PGS下应该写成：

$$
\pmb p_n^{'} = \pmb p_n -\frac{\pmb J_n\pmb u^{(k+1)} + \frac{C_n}{\Delta t}}{A_{11}}
$$
这就是法向冲量在PGS下的更新公式。记$w = \pmb J_n \pmb u^{(k+1)} + \frac{C_n}{\Delta t}$。

然后要看PGS的Clamp条件（44）式

$$
\begin{aligned}
&\pmb 0\le{}^{u}\pmb p_n^{(k+1)}
\;\perp\;
\phantom{}{}^{u}J_n^{(k)}\pmb u^{(k+1)}
+\frac{{}^{u}C_n^{(k)}}{\Delta t}
+\frac{\partial{}^{u}C_n^{(k)}}{\partial t}
\;\ge\pmb 0 
\end{aligned}
$$
这里其实就是对$\pmb p_n \ge 0$和$w \ge 0$的条件。注意PGS只对变量做clamp，所以这里只需要对$\pmb p_n$做clamp即可。

那么对应代码就是：

```cpp
void RigidSolver::solveNormal(SolverContact& contact) {
    if (contact.m_normal_mass <= 0) {
        return;
    }

	// 计算 Jn u
    const real vn = relativeVelocity(contact).dot(contact.m_normal);

	// 计算 (-Cn/dt - Jn u)/A11，这里A11是1/Jn M^{-1} Jn^T，即 m_normal_mass
    const real delta = (contact.m_bias - vn) * contact.m_normal_mass;

    const real old = contact.m_normal_impulse;
    
    // 算p_n，以及强制clamp在p_n >= 0 约束内。
    const real next = std::max<real>(0, old + delta);
    const real applied = next - old;
    
    // 记录新p_n
    contact.m_normal_impulse = next;

	// 如果新旧p_n之间没变化，就直接返回
    if (applied == 0) {
        return;
    }

	// 算出冲量，然后用冲量更新速度&角速度
    const Vector3 impulse = contact.m_normal * applied;
    applyContactImpulse(contact, impulse);
}
```

这里注意，是用`next - old`作为冲量。这是因为：

$$
\begin{aligned}
\pmb u^{'} &= \pmb r + M^{-1}\pmb J_n^T \pmb p_n^{new} \\
\pmb u &= \pmb r + M^{-1}\pmb J_n^T \pmb p_n^{old} \\
& \Rightarrow \\
\pmb u^{'} - \pmb u &= M^{-1}\pmb J_n^T(\pmb p_n^{new} - \pmb p_n^{old})
\end{aligned}
$$

也就是说，`next - old`才是导致速度变化的原因，而不是$\pmb p_n$本身。$\pmb p_n$是当前步骤累计的冲量。

所以这里 `impulse = contact.m_normal * applied`是在算$J_n^T(\pmb p_n^{new} - \pmb p_n^{old})$。而对于$M^{-1}$的计算则被挪到`applyContactImpulse`中了：

```cpp
void RigidSolver::applyContactImpulse(SolverContact& contact,
                                      const Vector3& impulse) {
    if (contact.m_dyn2 != nullptr) {
        contact.m_dyn2->ApplyImpulse(impulse, contact.m_r2);
    }
    if (contact.m_dyn1 != nullptr) {
        contact.m_dyn1->ApplyImpulse(-impulse, contact.m_r1);
    }
}

void DynamicRigidBody::ApplyImpulse(const Vector3& impulse, const Vector3& r) {
    m_velocity += impulse * m_mp.m_inv_mass;
    m_angular_velocity += MultiplyInvInertiaWorld(r.cross(impulse));
}
```

#### 摩擦约束

对应（51）式中的$A$的第二行和$x$相乘。此时变量是$\pmb \alpha$。

$$
\begin{aligned}
& \pmb J_D \pmb S_{11} \pmb J_n^T \pmb p_n + \pmb J_D \pmb S_{11} \pmb J_D^T \pmb \alpha + \pmb J_D \pmb r = 0 \\
& \pmb J_D \pmb M^{-1} \pmb J_n^T \pmb p_n + \pmb J_D \pmb M^{-1} \pmb J_D^T \pmb \alpha + \pmb J_D \pmb r = 0 \\
\end{aligned}
$$

然后和上面说的一样，使用盒模型近似$\pmb \alpha$和将$\pmb J_D$拆成两个切向：

$$
\begin{aligned}
\pmb J_D &= 
\begin{bmatrix}
J_t \\
-J_t \\
J_o \\
-J_o \\
\end{bmatrix}\\
\pmb \alpha &=
\begin{bmatrix}
\alpha_1 \\
\alpha_2 \\
\alpha_3 \\
\alpha_4 \\
\end{bmatrix} \\
\end{aligned}
$$
这样整个式子就变成四个等式：

$$
\begin{aligned}
& J_t M^{-1} J_n^\mathsf T p_n + J_t M^{-1} J_t^\mathsf T \alpha_1 - J_t M^{-1} J_t^\mathsf T \alpha_2 + J_t M^{-1} J_o^\mathsf T \alpha_3 - J_t M^{-1} J_o^\mathsf T \alpha_4 + J_t \mathbf r = 0 \\
&- J_t M^{-1} J_n^\mathsf T p_n - J_t M^{-1} J_t^\mathsf T \alpha_1 + J_t M^{-1} J_t^\mathsf T \alpha_2 - J_t M^{-1} J_o^\mathsf T \alpha_3 + J_t M^{-1} J_o^\mathsf T \alpha_4 - J_t \mathbf r = 0 \\
&J_o M^{-1} J_n^\mathsf T p_n + J_o M^{-1} J_t^\mathsf T \alpha_1 - J_o M^{-1} J_t^\mathsf T \alpha_2 + J_o M^{-1} J_o^\mathsf T \alpha_3 - J_o M^{-1} J_o^\mathsf T \alpha_4 + J_o \mathbf r = 0 \\
&-J_o M^{-1} J_n^\mathsf T p_n - J_o M^{-1} J_t^\mathsf T \alpha_1 + J_o M^{-1} J_t^\mathsf T \alpha_2 - J_o M^{-1} J_o^\mathsf T \alpha_3 + J_o M^{-1} J_o^\mathsf T \alpha_4 - J_o \mathbf r = 0 \\
\end{aligned}
$$

可以看到，式1其实就是式2取反。而式3就是式4取反。所以本质上只有两个式子。

$$
\begin{aligned}
&J_t M^{-1} J_n^{T} p_n + J_t M^{-1} J_t^{T} (\alpha_1 - \alpha_2) + J_t M^{-1} J_o^{T} (\alpha_3 - \alpha_4) + J_t \mathbf{r} = 0 \\[6pt]
&J_o M^{-1} J_n^{T} p_n + J_o M^{-1} J_t^{T} (\alpha_1 - \alpha_2) + J_o M^{-1} J_o^{T} (\alpha_3 - \alpha_4) + J_o \mathbf{r} = 0
\end{aligned}
$$
这里由于是盒子模型，所以：

$$
\begin{aligned}
p_t &= \alpha_1 - \alpha_2 \\
p_o &= \alpha_3 - \alpha_4 \\
\end{aligned}
$$
这样式子变成：

$$
\begin{aligned}
&J_tM^{-1}J_n^\mathsf Tp_n
+J_tM^{-1}J_t^\mathsf Tp_t
+J_tM^{-1}J_o^\mathsf Tp_o
+J_t\mathbf r
=0\\[6pt]
&J_oM^{-1}J_n^\mathsf Tp_n
+J_oM^{-1}J_t^\mathsf Tp_t
+J_oM^{-1}J_o^\mathsf Tp_o
+J_o\mathbf r
=0
\end{aligned}
$$

然后写成PGS迭代形式：

$$
\begin{aligned}
p_t &= -\frac{J_tM^{-1}J_n^T p_n + J_tM^{-1}J_o^T p_o + J_t\pmb r}{J_tM^{-1}J_t^T} \\
p_o &= -\frac{J_tM^{-1}J_n^T p_n + J_tM^{-1}J_t^T p_t + J_o\pmb r}{J_oM^{-1}J_o^T} \\
\end{aligned}
$$

注意分子，我们可以用

$$
\pmb J_t\pmb u = \pmb J_t \pmb r + \pmb J_t(M^{-1}J_n^T p_n + J_t^Tp_t + J_o^Tp_o)
$$
替换（$\pmb J_o \pmb u$同理），那么式子变成：

$$
\begin{aligned}
p_t &= p_t -\frac{\pmb J_t \pmb u}{J_tM^{-1}J_t^T} \\
p_o &= p_o -\frac{\pmb J_o \pmb u}{J_oM^{-1}J_o^T} \\
\end{aligned}
$$
和接触约束类似。

这样，我们就可以使用类似接触约束的代码去计算$p_t$和$p_o$了。注意最后将他们投影到$[-\mu p_n, \mu p_n]$区间内满足LCP约束。

```cpp
void RigidSolver::solveFriction(SolverContact& contact) {
	// uF_n
    const real max_friction = contact.m_friction * contact.m_normal_impulse;

    for (int i = 0; i < 2; ++i) {
        if (contact.m_tangent_masses[i] <= 0) {
            continue;
        }

		// 得到当前对应tangent
        const Vector3& tangent =
            i == 0 ? contact.m_tangent1 : contact.m_tangent2;

		// 求tangent方向上的速度 J u
        const real vt = relativeVelocity(contact).dot(tangent);

		// - v / JM^{-1}J^T
        const real delta = -vt * contact.m_tangent_masses[i];

        const real old_impulse = contact.m_tangent_impulses[i];
        // 新冲量，但是要clamp在[-max_friction, max_friction]之间
        const real new_impulse =
            std::clamp(old_impulse + delta, -max_friction, max_friction);

		// 后面和接触冲量一样，应用冲量到物体上
        const real applied = new_impulse - old_impulse;
        contact.m_tangent_impulses[i] = new_impulse;

        if (applied != 0) {
            applyContactImpulse(contact, tangent * applied);
        }
    }
}
```

### 位置积分

在上述解约束之后，我们得到了最新的速度&角速度。最后我们做（42）式中的位置积分：

```cpp
void RigidSolver::integrateTransform(DynamicRigidBody& body, real dt) {
    Transform trans = body.GetTransform();

    trans.m_position += body.GetVelocity() * dt;

    Vector3 angular_velocity = body.GetAngularVelocity();
    Vector3 omega_dt = angular_velocity * dt;
    real angle = omega_dt.norm();

    if (angle > kREAL_EPSILON) {
        auto axis = omega_dt / angle;
        const Quaternion dq(Eigen::AngleAxis<real>(angle, axis));
        trans.m_rotation = (dq * trans.m_rotation).normalized();
    }

    body.Teleport(trans);
}
```

这里也是将公式拆开，变成速度的和角速度的单独公式。注意角速度这里是直接用四元数的增量公式，而不是用的矩阵形式。

注：综合速度积分和位置积分，你会发现我们用的就是半隐式欧拉积分法。

你可以看到物体很快就炸开了并不停地弹跳。

这是因为当前理论模型工作在**速度层**，他是通过给物体一个速度，让物体下一帧能刚好满足约束（物体刚好贴着）。但是满足约束之后速度仍在，在下下帧之后会因为这个速度继续移动物体，导致物体不停地移动。

这里其实有两种抖动：

1. 单个盒子本身的抖动。这是因模型本身工作在速度层的问题。
2. 盒子堆叠时的抖动。这是因为每次迭代中，冲量都从头开始算。盒子堆叠层数越多，迭代次数需要的越多。但是目前我们引擎里是固定60次的次数，所以随着盒子层数增多，PGS算出的结果会离真实解偏差越来越多，这导致系统越来越不稳定。

而解决方法分别是：

1. 位置约束求解：因为模型完全工作在加速度层（即确保$\dot{C} = 0$，所以我们可以额外在位置层进行约束求解，以保证$C = 0$也成立。
2. Warm Start：将上一帧算出的接触冲量作为这一帧的初始值，以减少PGS需要的迭代次数。

#### Baumgarte Stability

这里我们可以先小小地Hack一下让盒子稳定。使用一种叫**Baumgarte Stability**的方法。这里用在速度层，后面等我们加上位置约束求解时会将他挪到位置层。

这里盒子不稳定是因为每帧的速度残留导致物体移动。那我们可以让他每帧算的速度小一些来减少这种问题。

方法是在速度层LCP上增加一个$\beta$参数：

$$
\begin{aligned}
\text{原来：} & 0 \le \pmb p_n \perp \pmb J_n \pmb u + \frac{C_n}{\Delta t} \ge 0 \\
\text{现在：} & 0 \le \pmb p_n \perp \pmb J_n \pmb u + \beta\frac{C_n}{\Delta t} \ge 0 \\
\end{aligned}
$$

这样在接触约束中，我们的计算公式就是：

$$
\pmb p_n^{'} = \pmb p_n - \frac{\pmb J_n \pmb u + \beta \frac{C_n}{\Delta t}}{A_{11}}
$$

但就算是这样，每次还是会有额外速度。那我们就直接设置一个死区`slope`，当在这个死区内我就认为满足约束了（穿透深度为0），将式子变为：

$$
\pmb p_n^{'} = \pmb p_n - \frac{\pmb J_n \pmb u + \beta \frac{\max (C_n - \text{slop}, 0)}{\Delta t}}{A_{11}}
$$
